# 🤖 JARVIS AI Web App (Windows & Android)

A futuristic, sci-fi cybernetic AI assistant web application inspired by Stark Industries' J.A.R.V.I.S., engineered with Progressive Web App (PWA) architecture to run natively on **Windows (10/11)** and **Android** mobile devices.

---

## 🌟 Key Features

1. **Full Dual-Platform Support (Windows & Android):**
   - **Progressive Web App (PWA)**: Install directly from your browser as a standalone app with desktop/home screen shortcuts.
   - **Responsive Sci-Fi UI**: Seamlessly adapts from desktop ultrawide monitors to Android touch screens.

2. **Acoustic Voice Engine:**
   - **Speech Synthesis (TTS)**: JARVIS talks back with a synthesized AI voice when responding to directives.
   - **Speech Recognition (STT)**: Tap the microphone icon to speak commands directly into the terminal.

3. **Tactical Command Terminal:**
   - Interactive console responding to voice or text directives like `status`, `diagnostics`, `telemetry`, `security scan`, `who are you`, and custom prompts.
   - Quick Protocol action shortcuts for one-click status checks.

4. **Arc Reactor Interactive Visualizer:**
   - High-tech glowing rotating rings with dynamic audio visualizer waveforms and particle canvas background.

5. **Offline & Fast Performance:**
   - Equipped with `sw.js` (Service Worker) caching and `manifest.json` for offline resilience.

## 🚀 How to Run & Open

### Option 1: Double-click to open
Simply double-click `index.html` in File Explorer (`C:\Users\abhi\OneDrive\Desktop\jarvis\index.html`) to launch it in your default browser (Chrome, Edge, Firefox, Brave).

### Option 2: Run with a local HTTP server
For full PWA installation and service worker features:
- If you have Python installed: `python -m http.server 8080`
- If you use VS Code / IDE: Right-click `index.html` and choose **"Open with Live Server"**.

## 📲 How to Install as an App

### On Windows (Chrome or Edge):
1. Open the website in Google Chrome or Microsoft Edge.
2. Click the **Install** button on the top-right of the navigation bar, or click the **Install icon (computer with down arrow)** in your browser's address bar.
3. JARVIS will install and appear in your Start Menu and Desktop as a standalone window app without browser tabs.

### On Android (Chrome):
1. Open the website on your Android phone's Chrome browser.
2. Tap the three dots (⋮) in the top-right corner.
3. Select **"Add to Home screen"** or **"Install app"**.
4. Launch JARVIS from your app drawer in full-screen mode.
